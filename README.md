# Orient - Watch Store Landing Page

A static landing page for a watch store, built with HTML5 and CSS3.

## Features
- Top bar and navbar with 6 links and a "pages" dropdown menu
- Sale banner and hero section
- 3 category cards: men's, women's and kids' watches
- "Trending this week" section with 4 product cards
- "You may like" section with 4 product cards
- Testimonial section, 3 news cards and 4 service boxes
- Footer with newsletter box and link columns

## Tech Stack
HTML5, CSS3, Font Awesome, Google Fonts
